YOUR SITE FOR THE "Portfolio" REPOSITORY

Your site address will be:  https://anikasola.github.io/Portfolio/   (capital P)

1. Unzip this file, then OPEN the folder it creates.
2. In your GitHub repository, DELETE the old "anika-site" folder:
   open it, click the three dots (...) next to the folder name, choose Delete directory, and commit.
3. Click Add file > Upload files. Drag in the 7 files from inside the unzipped folder
   (index.html and the icon and image files). Do NOT drag the folder itself.
   Commit changes.
4. Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
5. Wait a few minutes, then open https://anikasola.github.io/Portfolio/
   and do a hard refresh (Cmd+Shift+R).

index.html must sit at the top level of the repository, not inside any folder.
